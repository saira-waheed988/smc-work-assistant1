# SMC Work Assistant - Phase 1: Area Tracker

## Setup (Windows)
1. Python 3.10+ install karein (python.org, "Add to PATH" tick karein).
2. Is folder mein Command Prompt kholein:
   pip install -r requirements.txt
   streamlit run app.py
3. Browser mein app khul jayegi.

## Test karna
`python make_sample_data.py` -> sample_data/ mein synthetic files banti hain
(area_previous.xlsx, area_updated.xlsx). Inhein app mein upload karein.
